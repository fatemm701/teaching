06 对数函数

这一讲的目标

学完这一讲，你要能做到：在 𝑎𝑥 =𝑁 与 𝑥 =log𝑎⁡𝑁 之间自由转换，并守住"真数大于 0"。

这一讲要记住的一句话

对数就是"反过来问指数"：2 的几次方等于 7，那个次数就是 log2⁡7。所有性质都从这一句推。

准备 开讲前先做两题

先做两题

  1. 上一讲留的问题：2𝑥 =8 中 x = 3。那 2𝑥 =7 呢？x 是什么数？
  2. 23 =8，这里面"2、3、8"分别叫什么名字？（底数？指数？结果？）

01 对数是这么来的

23 =8 是"已知底数和次数，求结果"。但实际遇到的往往是反过来：已知底数和结果，求次数。这个"次数"写不出来是个数，只能造一个新记号给它。

定义

若 𝑎𝑥 =𝑁（𝑎 >0 且 𝑎 ≠1，𝑁 >0），就记作 𝑥 =log𝑎⁡𝑁，读作"以 a 为底 N 的对数"。
a 叫底数，N 叫真数。约定：底数必须正且不等于 1，真数必须大于 0。

本讲唯一的根

𝑎𝑥 =𝑁 ⇔𝑥 =log𝑎⁡𝑁
这两个式子是同一句话的两种写法。所有题都先把它翻成你能做的那一边。

图 1 指数式与对数式的互化示意

图 1 从左边翻到右边，只有两件事：底数 a 不动，结果 N 和次数 x 换个位置。

例题 1（互化）

题目　把下面四句来回翻：23 =8、3−2 =1/9、log2⁡16 =4、log3⁡9 =2。

23 =8 ⇔log2⁡8 =3。

3−2 =1/9 ⇔log3⁡19 = −2。

log2⁡16 =4 ⇔24 =16。

log3⁡9 =2 ⇔32 =9。

旁注

互化只动两处：底数始终待在下面不动，真数 N 和次数 x 交换位置。按住这两条去写，不会把 2 和 8 弄反。

02 四条性质，全部从互化推出来

下面四条不要背，每条都用一次 𝑎𝑥 =𝑁 ⇔𝑥 =log𝑎⁡𝑁 当场推给自己看。

结论 为什么（用互化推）
log𝑎⁡1 =0 𝑎0 =1
log𝑎⁡𝑎 =1 𝑎1 =𝑎
𝑎log𝑎⁡𝑁 =𝑁 就是定义本身再代一次
log𝑎⁡(𝑎𝑥) =𝑥 同上，反向代
图象上的三条（和 05 讲对照）

必过点 (1, 0)：因为 log𝑎⁡1 =0。注意是指数函数那个 (0,1) 的两个数换了位置。
定义域 (0, +∞)，值域 R：正好和指数函数反过来。
a > 1 递增，0 < a < 1 递减：和指数函数同向。

为什么会跟 y = x 对称

因为 𝑦 =log𝑎⁡𝑥 就是 𝑦 =𝑎𝑥 把 x、y 互换。互换坐标 = 关于直线 y = x 翻折。这和 01 讲"图象是点的集合"是同一套逻辑：点换了位置，图就换了位置。

图 2 𝑦 =2𝑥 与 𝑦 =log2⁡𝑥 关于直线 y = x 对称

图 2 把 𝑦 =2𝑥 沿直线 y = x 折过去，正好压在 𝑦 =log2⁡𝑥 上。点也对得上：指数曲线过的 (0, 1)，翻过去就是对数曲线过的 (1, 0)。

旁注

对数曲线与指数曲线的对称，折痕是斜的直线 y = x。(0,1) 翻过去是 (1,0)；x 轴上方那半边翻过去，就变成 y 轴右边那半边。拿张纸盖住一半折一下，比看十遍式子清楚。

要点 说明
函数 𝑦 =log𝑎⁡𝑥（𝑎 >0，𝑎 ≠1）
定义域 (0, +∞)——只能对正数取对数
值域 R——可以取到任何实数（指数函数的值域反过来）
必过点 (1, 0)，因为 log𝑎⁡1 =0
单调性 a > 1 递增；0 < a < 1 递减（和指数函数同向）
与指数 关于直线 y = x 对称

03 "真数大于 0"从哪来

回到 𝑎𝑥 =𝑁：左边是正数的任何次方，结果永远大于 0。所以 N 不可能 ≤ 0，也就不能对 0 或负数取对数。

例题 2

题目　求 𝑦 =log2⁡(𝑥 −1) 的定义域。

真数 x − 1 > 0。

x > 1，即 (1, +∞)。

顺带：图象是把 𝑦 =log2⁡𝑥 右移 1 个单位（回扣 01），过点 (2, 0)。

例题 3（叠两层限制）

题目　求 𝑦 =log0.5⁡(𝑥 −1) 过哪个点、是增还是减。

定义域 x > 1。

真数为 1 时对数为 0：x − 1 = 1 ⇒ x = 2，过 (2, 0)。

底 0.5 < 1 ⇒ 在定义域上单调递减。

练习（先写完，再点开对答案）

A 组 · 互化与求值

  1. 把 52 =25 写成对数式。
  2. 把 log4⁡16 =2 写成指数式。
  3. 求 log2⁡32、log3⁡127、log7⁡1。
  4. 求 2log2⁡5、log4⁡2。
答案
  1. log5⁡25 =2。 2. 42 =16。 3. 5；−3；0。 4. 5；log4⁡2 =12（因为 412 =2）。

B 组 · 定义域与性质

  1. 𝑦 =log3⁡(𝑥 +2) 的定义域、必过点。
  2. 𝑦 =log0.5⁡(𝑥 −1) 是增还是减？为什么？
  3. 𝑦 =log2⁡𝑥 与 𝑦 =log2⁡(𝑥 +3) 的位置关系？
答案
  1. x > −2，即 (−2, +∞)；真数为 1 时 x + 2 = 1 ⇒ 过 (−1, 0)。 2. 减函数。底数 0.5 在 (0,1) 之间。 3. 后者是把前者左移 3 个单位（括号里加 3 → 往左）。

C 组 · 比较与复合

  1. 比较 log2⁡3 与 log3⁡2，中间用 1 隔开。
  2. 比较 log0.5⁡3 与 log0.5⁡5。
  3. 求 𝑦 =log2⁡(𝑥2 −1) 的定义域。
答案
  1. log2⁡3：真数 3 >2 ⇒ log2⁡3 >log2⁡2 =1。log3⁡2：真数 2 <3 ⇒ log3⁡2 <log3⁡3 =1。所以 log2⁡3 >1 >log3⁡2。 2. 底 0.5 <1，递减；由 3 <5 ⇒ log0.5⁡3 >log0.5⁡5。 3. 𝑥2 −1 >0 ⇒ 𝑥 < −1 或 𝑥 >1，即 ( −∞, −1) ∪(1, +∞)。

易错 三个最容易犯的错

错误 根子在哪 怎么办
写 log2⁡8 =3 时把 2 和 8 弄反 互化时位置记混 只记两件事：底数不动、N 与 x 换位。写之前先念一遍"以 2 为底 8 的对数是几"。
不查真数就求定义域 把对数当成普通函数 看到 log，第一个动作就是"真数 > 0"。
以为 log𝑎⁡(𝑀 ⋅𝑁) =log𝑎⁡𝑀 ⋅log𝑎⁡𝑁 把对数和乘法混淆 正确的是 log𝑎⁡(𝑀𝑁) =log𝑎⁡𝑀 +log𝑎⁡𝑁（乘法变加法）。不确定就代一组数验证。

自测 这一讲的过关清单

  • 我能说出对数是怎么被"逼"出来的（反过来问指数）。
  • 我能在 𝑎𝑥 =𝑁 与 𝑥 =log𝑎⁡𝑁 之间秒换，不弄反位置。
  • 我能用互化推出 log𝑎⁡1 =0、log𝑎⁡𝑎 =1、𝑎log𝑎⁡𝑁 =𝑁。
  • 我看到 log 就先写"真数 > 0"。
  • 我能说出对数图象必过 (1,0)、与指数图象关于 y = x 对称。
  • 我能用中间数 1 比较 log2⁡3 与 log3⁡2。
课后布置
  1. 互化练习 10 组（指数 ⇄ 对数）。 2. 求 5 个对数函数的定义域，每个都从列不等式开始。 3. 画 𝑦 =log2⁡𝑥 与 𝑦 =2𝑥，并画出 𝑦 =𝑥，观察翻折。
