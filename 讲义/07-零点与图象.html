07 零点与图象

这一讲的目标

学完这一讲，你要能做到：把"解方程"翻译成"看交点"，并用零点存在定理判断根的范围。

这一讲要记住的一句话

零点是一个数，不是点。方程的根、函数图象与 x 轴的交点横坐标、零点——这三件事说的是同一件事。

准备 开讲前先做三题

先做三题

  1. 𝑓(𝑥) =𝑥2 −4 的零点是哪两个数？
  2. "𝑓(0) < 0 且 𝑓(2) > 0，所以 f 在 (0,2) 内一定有一个零点"——这句话一定对吗？
  3. 𝑥 +1 =2𝑥 有几个解？能看出来吗？

01 三种说法，一件事

定义

使 𝑓(𝑥) =0 的实数 x 叫做函数 𝑓(𝑥) 的零点。

本讲核心的翻译表

方程 𝑓(𝑥) = 0 的根 ⇔ 函数 y = 𝑓(𝑥) 的零点 ⇔ 图象与 x 轴交点的横坐标
三句是同一件事的三种说法。考试里见哪一句，都能翻成最方便的那一句。

零点不是点

"零点是 (2, 0)"——错。零点是数 2。写成点的是交点。

02 数形结合三步法

必记 · 三步

① 把方程拆成左边一个函数、右边一个函数；② 各画一条曲线；③ 看交点的个数与位置。
这比"硬解方程"强，因为很多方程根本解不出来（比如 2𝑥 =𝑥 +1 之外的 2𝑥 =3 −𝑥）。

例题 1

题目　解 |x| = 2，并说明用的是哪一步。

① 拆：左边 y = |𝑥|，右边 y = 2（一条水平线）。

② 画：V 字形和水平线。

③ 看：两个交点，横坐标 x = 2 和 x = −2。

所以方程有两个解。

旁注

纯算术解 |𝑥| = 2 容易只写出 2，漏掉负数那个解；画成两条线，个数一眼看得出来。

图 1 方程的解 = 交点横坐标。线画出来，个数一目了然；纯算术容易漏掉负数那个解。

03 零点存在定理：三要素缺一不可

定理

如果函数 𝑦 =𝑓(𝑥) 在区间 [𝑎,𝑏] 上的图象是连续不断的一条曲线，并且 𝑓(𝑎) ⋅𝑓(𝑏) <0，那么函数在 (𝑎,𝑏) 内至少有一个零点。

要素 少了会怎样
① 连续不断 断了就能跳过 x 轴，两端异号也没有零点
② 两端函数值异号 两端同号时，中间可能有零点（如 𝑥2 在 [−1,1]），也可能没有
③ 结论是"至少一个" 不是"只有一个"，个数要靠别的方法（单调性）再确定

例题 2（反例：为什么不连续就失效）

题目　𝑓(𝑥) =1/𝑥 在 [−1, 1] 上，𝑓( −1) = −1，𝑓(1) = 1，异号。有零点吗？

f(−1)·f(1) = −1 < 0，按定理好像该有零点。

但 1/x 永远不等于 0，没有零点。

原因：f 在 x = 0 处断开了，定理的第一个条件不满足。

组合拳：单调 + 异号 ⇒ 唯一零点

由 03 讲，若 f 在 [a,b] 上单调，那么图象一路走，最多穿过 x 轴一次；再加上 𝑓(𝑎)·f(b) < 0 保证至少一次，合起来就是恰好一个。

例题 3

题目　证明 𝑓(𝑥) =𝑥3 +𝑥 −1 在 (0, 1) 内恰有一个零点。

连续性：多项式显然连续。

异号：f(0) = −1 < 0，𝑓(1) = 1 > 0 ⇒ 至少一个。

单调：𝑥3 和 𝑥 都递增，和为递增 ⇒ 最多一个零点。

结论：恰好一个。

练习（先写完，再点开对答案）

A 组 · 求零点

  1. 𝑓(𝑥) =2𝑥 −6
  2. 𝑓(𝑥) =𝑥2 −5𝑥 +6
  3. 𝑓(𝑥) =2𝑥 −8
  4. 𝑓(𝑥) =log2⁡(𝑥 −1)
答案
  1. 3。 2. 2 和 3。 3. x = 3。 4. x = 2（真数 = 1）。

B 组 · 数交点

  1. |x| = 2 有几个解？
  2. 2𝑥 =𝑥 +1 有几个解？（画两条曲线）
  3. 𝑥2 =2𝑥 有几个解？
答案
  1. 两个（2 和 −2）。 2. 两个（x = 0 和 x = 1）。这是典型的必须画图才不漏解的题。 3. 两个（x = 0、2）。

C 组 · 定理应用

  1. f(x) = 2x + 1，在 (0, 1) 内。能用零点存在定理说明有零点吗？
  2. f(x) = 𝑥3 − x − 1 在 [1, 2] 内是否恰有一个零点？
  3. 若 f 在 [a,b] 上单调递增且 𝑓(𝑎) < 0 < 𝑓(𝑏)，f 在 (a,b) 内有几个零点？
答案
  1. 不能。𝑓(0)=1 > 0，𝑓(1)=3 > 0，两端同号，条件②不满足（事实上它的零点是 −1/2，本来就不在 (0,1) 里）。这题是故意设的坑。 2. 是。𝑓(1) = −1 < 0，𝑓(2) = 5 > 0 ⇒ 至少𝑥3 与 −x 都递增 ⇒ 最多一个。恰一个。 3. 恰好一个。

易错 三个最容易犯的错

错误 根子在哪 怎么办
把零点写成点 (2, 0) "零点"这个词片面的字面理解 零点是一个数；交点才是点。
只由"两端异号"就断定恰有一个零点 漏掉"至少"两个字 要证唯一，必须再加一句单调性。
两端同号就说"没有零点" 把定理反着用了 定理只给"异号⇒有"，不给"同号⇒无"。

自测 这一讲的过关清单（也是这七讲的总结）

  • 我能说出零点、方程的根、交点横坐标是同一件事。
  • 我能用"拆成两个函数 + 画图 + 数交点"解决至少两个解的问题。
  • 我能背出零点存在定理的三个条件，并解释为什么"连续"不能少。
  • 我能用"单调 + 异号"证"恰有一个零点"。
  • 我能把 01（图象动）、03（单调）、07（交点）串成一句话来说。
课后布置
  1. 求 6 个函数的零点。 2. 3 道"恰有一个零点"的证明题（必须写出连续、异号、单调三部分）。 3. 复习：合上书，把七讲各用一句话说出来，录给你自己听。
