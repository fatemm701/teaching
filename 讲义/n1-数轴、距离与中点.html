N1 数轴、距离与中点

这一讲的目标

学完这一讲，你要能做到：看到数轴上任意两点，立刻说出谁大谁小、相距多远、中点在哪，并且用一句话说清理由。

这一讲要记住的一句话

数轴是一根尺子：位置带正负号（往右为正），距离只看长短（永不为负），中点是两头位置的平均数。右边减左边一定大于 0，正是因为"往右走"被规定成了正方向。

准备 开场四题

四题都是小学会做的算术。做不出来不要紧，要留意的是第四题：3 和 9 的中间那个数，你算的是 6 还是 12？

开场四题

  1. 2 − 5 = ？ 3 − 8 = ？
  2. 11 − (−3) = ？ (−2) − 5 = ？
  3. 班里有 11 个同学，从第 3 号排到第 8 号，一共几个人？排在第 5 号的人，离 3 号和 8 号各隔几个人？
  4. 3 和 9 的中间是几？
答案
  1. −3；−5。 2. 14；−7。 3. 6 个人（8 − 3 + 1，因为两头都算上）；第 5 号离 3 号、离 8 号都是 2 个人——两头各让出同样多，这正是"中点"的意思。 4. 6。 第 4 题答 12 的，是 3 + 9 之后忘了除以 2；答 6 却说不出理由的，这一讲正是补这个理由。
从今天起，"-" 有两个身份

在 2 −5 里，它是减号（做一个动作：减）；在 −3 里，它是负号（一个数的姓，不表示动作）。你算术没问题，选哪个意思不会错；但只要开始问"数轴上右边减左边为什么大于 0"，一定得先把这两个身份分开。

01 数轴就是一根带箭头的刻度尺（≈10 分钟）

数轴上所有的"怪现象"——负号、绝对值、右边减左边——都来自一条人为的约定：规定往右是增加的方向。

数轴：原点、正方向、单位长度

三要素：原点（0 的位置）、正方向（往右）、单位长度（每一格一样长）。缺一条就不是数轴。

三要素
  1. 原点：0 站在哪儿，先钉死。它是数轴的"起点"，不是"最小"，左边还有数。
  2. 正方向：规定往右为增加。这一条规定，后面所有结论都是从它推出来的。
  3. 单位长度：每一格一样长。没有它，"离得远"就没法比较。

一个数有两层意思

数轴把两件事钉在了一起，这是它最大的用处：

要点 说明
作为一个数 它有自己的大小位置：3 比 −5 大。
作为尺子上的一点 它有确定的位置：在数轴上就是那个刻度的点。
两层放在一起 比大小这件事，从此可以看成比位置：谁在右边，谁就大。不用再背口诀。
为什么左边的数小

不是因为"负号的东西更小"，而是因为我们把往右规定成了增加。顺着增加的方向走，越走越大；逆着走，越走越小。左边就是从右往左走，所以左边更小。

别把原点当成"最小"

原点是位置起点，不是大小起点。−100 在原点左边很远，但它比 −1 还小——左边越远越小。数轴上没有"最小的数"。

练习 01

  1. 在数轴上标出 −2、0、1.5、3，然后用"＜"把它们从小到大排好。
  2. −4 和 −1，哪个在右边？哪个大？
  3. 从 0 出发，先向右走 3 格，再向左走 7 格，最后停在哪个数上？
  4. 单位长度如果改成原来的两倍，数轴上 3 的位置会往哪边挪？
答案
  1. −2 ＜ 0 ＜ 1.5 ＜ 3。 2. −1 在右边，−1 大。越靠右越大，跟"负数就更小"没关系。 3. 停在 −4。3 − 7 = −4，也可以数格：先到 3，再往回退 7 格。 4. 往右挪。每格变长，同样的数就走得更远；单位长度变了，整根尺子的疏密就变了。

02 右边减左边，结果一定大于 0（≈20 分钟）

这句话不是要背的规律，它是一条能被验算的事：随便挑两个数，右边那个减左边那个，结果一定是正数。

右边减左边：每一步向右都是正的

四步验算。箭头一律朝右，表明"右减左"算出来的永远是一个向右的量。

四种情况，一个结论

四种情况，一个结论

四种情况，一个结论

取 −2 与 −5（−2 在右边）：−2 −( −5) =3 >0

取 −5 与 −2（−2 在右边）：−2 −( −5) =3 >0

取 0 与 3：3 −0 =3 >0

取 −5 与 3：3 −( −5) =8 >0

不管挑哪两个数、差多少、隔不隔 0，只要减的顺序是"右减左"，结果就是正数。

为什么一定大于 0

这里只需要一句话，不需要更多：

理由

设左边的数是 a，右边的数是 b。因为 b 在 a 的右边，所以从 a 出发往右走若干格才能到 b。往右走的格数记作 d，那么
𝑏 =𝑎 +𝑑（其中 𝑑 >0）
两边同减去 a，得到
𝑏 −𝑎 =𝑑 >0
d 是"往右走了几格"，格数当然大于 0。所以"右减左大于 0"从头到尾只是一句"往右走要走正格数"。

这条结论真正的用处

它把"比较大小"变成了一件可以做出来的事：要判断 a 和 b 谁大，只要算 𝑏 −𝑎，看结果是正还是负。

例题 1

题目　比较 −3.5 和 −1.2 的大小。

① 找右边的数：−1.2 在 −3.5 右边。

② 右减左：( −1.2) −( −3.5) =2.3 >0。

③ 结果大于 0，说明右边的数更大，即 −1.2 > −3.5。

旁注

两个都是负数，也能比较；比的是位置，不是"负号的多少"。

三种常见错法
  • "−5 比 −2 大，因为 5 比 2 大"：忘了负号说的是"在原点的左边"。左边离原点越远，数越小。
  • "−3.5 比 −1.2 大，因为 3.5 比 1.2 大"：同上，小数点位置不改变左右关系。
  • "负负得正，所以 −2 − (−5) 是负的"：这是把符号法则记串了。算一下就知道是 3；而且它表示"从 −5 往右走 3 格到 −2"，方向是右，必然是正的。

练习 02

  1. 用"右减左、看正负"的方法，比较 −7 和 −2。
  2. 算一算：4 −( −6)、( −6) −4。两个结果各说明哪边大？
  3. 不计算，判断真假：−0.4 ＞ −0.45。
  4. 已知 𝑚 −𝑛 = −5，m 和 n 谁大？为什么？
答案
  1. 右减左：(−2) − (−7) = 5 ＞ 0，所以 −2 ＞ −7。 2. 4 − (−6) = 10 ＞ 0，4 大；(−6) − 4 = −10 ＜ 0，−6 小。同一个"减"，谁减谁，结论正好相反。 3. 真。−0.4 在 −0.45 右边：两者都是原点左边，离原点近的更大。 4. m 小。m − n ＜ 0 说明把 n 当作右边的数时结果是负的，也就是 m 在 n 左边。

03 绝对值：一根线只量长短，不管朝哪边（≈25 分钟）

第 02 节把"右减左"固定在正数上。但如果我只想知道离得多远、不在乎方向，那么"左减右"算出来的负数也别浪费——把它的负号扔掉就行。这个"扔掉负号"的动作，就是绝对值。

绝对值：到原点的距离

|5| 和 | −3| 量的都是"格数"：一个向右数了 5 格，一个向左数了 3 格。

定义

在数轴上，一个数到原点的距离，叫做这个数的绝对值，记作 |a|。
写成计算规则（两条，按数的正负分开）：
当 𝑎 ≥0 时，|𝑎| =𝑎；当 𝑎 <0 时，|𝑎| = −𝑎。
注意第二条：a 本身是负的，前面的那个负号是"再取一次相反数"，所以 −a 是正数。| −5| = −( −5) =5。

"去掉负号"不是定义，只是一种说法

先说它是距离，"去掉负号"只是这句话在计算上的样子。反过来就很危险：−| −3| = −3，这里的三条横线里，最前面那个负号不是绝对值的一部分，它表示"把距离 3 取相反数"，所以结果是 −3 而不是 3。凡是写错这一题的，都是把绝对值当成了"见负号就删"的机械动作。

两个数之间的距离

把第 02 节和上面的定义接起来，就得到这一讲最有用的一条公式：

必记 · 两点距离

数轴上两点 𝑎、𝑏 之间的距离 =|𝑎 −𝑏|。
因为 |𝑎 −𝑏| 把"右减左"的正数原样留下，把"左减右"的负数翻了正——无论谁减谁，量出来的都是同一段长度。

主公式（万能）

距离 = |𝑎 −𝑏|

不知道谁在左边也能用，带分数、小数、负数都能用。

快捷算法（懒人版）

已经知道 a 在右：距离 = 𝑎 −𝑏

算出来直接是正数，省掉绝对值号。看不出谁在右边时，别偷懒。

例题 2

题目　求数轴上 −2 与 5 之间的距离。

① 用主公式：|5 −( −2)| =|7| =7。

② 用快捷算法：5 在右边，5 −( −2) =7。

③ 反过来减也不会错：|( −2) −5| =| −7| =7。

旁注

三种算法同一段长度。顺序只影响符号，绝对值一取，只剩下长短。

例题 3

题目　求 −7.5 与 3.5 之间的距离。

① 一个是负数、一个是正数，跨过了 0，但公式照样直接用。

② |3.5 −( −7.5)| =|11| =11。

③ 检验：−7.5 到 0 是 7.5，0 到 3.5 是 3.5，7.5 + 3.5 = 11。对上了。

旁注

跨 0 的时候，距离正好是两段绝对值相加；后面 04 节专门讲这件事。

反过来问：离某个点有多远

|𝑥 −𝑎| 这个写法，读出来是一句话："x 到 a 的距离是多少"。所以解 |𝑥 −𝑎| =𝑑 这样的式子，不要拆绝对值符号去讨论正负，直接在数轴上找点：

一句话读法

|𝑥 −2| =3 的意思是：x 离 2 有 3 个单位。那就从 2 出发，向右走 3 到 5，向左走 3 到 −1。答案左右各一个点。
|𝑥 −2| <3 的意思是：x 离 2 不到 3。答案是 −1 到 5 之间的一段（不含两头），不是一个点。

别把绝对值拆开写

看到 |𝑥 −2| 就写"当 x ≥ 2 时它等于 x − 2，当 x ＜ 2 时它等于 2 − x"——这样做没错，但初一阶段这样做只会把自己绕进去。先问"它表示多远的距离"，再找点。

练习 03

  1. 计算：| −9|、|0|、−| −4|、|3 −8|。
  2. 求 4 与 −6 之间的距离；求 −2.5 与 −1 之间的距离。
  3. 已知 |x| = 4，求 x。在数轴上把两个答案标出来。
  4. 已知 |𝑥 −3| =2，求 x。
  5. 一句话解释：为什么 |𝑎 −𝑏| 和 |𝑏 −𝑎| 一定相等？
答案
  1. 9；0；−4；5。 2. |4 −( −6)| = 10；|( −1) −( −2.5)| = 1.5。 3. x = 4 或 x = −4。离原点 4 个单位，左右各一个。 4. x = 5 或 x = 1。先读成"x 离 3 有 2 个单位"，再左右各走 2。 5. 它们量的是同一段长度，只是从右往左量还是从左往右量。方向相反的两个数，绝对值相同。

04 跨过 0 的那一段：为什么不能"按大小硬减"（≈20 分钟）

这是最容易出错的地方，也是很多人以为"数轴一跨 0 就不对"的地方。公式没错，错的是"从大的数减小的数"这个习惯。

跨过 0 的距离：量出来是 7 不是 -7

A 在 −5、B 在 2。这段距离从左往右量，是 5 + 2 = 7。

两种算法对照

两种算法对照

两种算法对照

算法①（按公式）：|2 −( −5)| =|7| =7，一步到位。

算法②（按段拼）：从 −5 走到 0 是 5 个单位，从 0 走到 2 是 2 个单位，合起来 5 + 2 = 7。

算法③（习惯的"大减小"）：2 −5 = −3——错。5 是 | −5|，不是 −5，把绝对值当成了数本身。

"大减小"为什么会出错

−5 和 2 跨过了 0，两个数在原点的两侧。"大减小"用到的是 | −5| =5，等于把点从 −5 搬到了 +5，位置全变了。所以跨 0 时，要么用公式带负号一起算，要么老老实实按两段拼，都不能先取绝对值再减。

例题 4

题目　数轴上 A 表示 −7，B 表示 1.5，求 AB 的长度。

① 判断位置：−7 在原点左边，1.5 在右边，跨 0。

② 用公式：|1.5 −( −7)| =|8.5| =8.5。

③ 用段拼验证：−7 到 0 是 7，0 到 1.5 是 1.5，7 + 1.5 = 8.5。两种算法一致。

旁注

跨 0 且数字不整齐时，两步互相验证最保险：公式算一遍，段拼估一遍，差得远就是算错了。

怎么一眼看出"跨没跨 0"

要点 说明
同号（都在右） 如 2 与 7：直接相减，7 − 2 = 5。
同号（都在左） 如 −7 与 −2：右边那个是 −2，−2 − (−7) = 5。
异号（一左一右） 如 −5 与 2：跨 0，距离 = 5 + 2，也就是两边的绝对值相加。
有一个是 0 如 0 与 −4：距离就是那个数的绝对值，4。

练习 04

  1. 求 −3 与 4 之间的距离（公式一次、段拼一次，两法对照）。
  2. 求 −8 与 −3 之间的距离。
  3. 求 −7.5 与 3.5 之间的距离。
  4. 甲说"−5 比 2 大，因为 5 比 2 大"，乙说"−5 和 2 之间隔了 3 个单位"。两人各错在哪里？
答案
  1. |4 −( −3)| = 7；段拼：3 + 4 = 7。 2. |( −3) −( −8)| = 5；都在原点左边，段拼 (−8 到 0 是 8，−3 到 0 是 3，8 − 3 = 5) 也对。 3. |3.5 −( −7.5)| = 11。 4. 甲错在把 | −5| 当成 −5 本身，−5 在原点左边，比 2 小；乙错在把两个绝对值相减（5 − 2 = 3），跨 0 的时候应该是相加，实际是 7。

05 中点：把两头拉平的那个位置（≈25 分钟）

"中点"这个名字已经说出了它是怎么算出来的：中间，就是两边一样长。

中点：两边各走一半

a 到 m 与 m 到 b 一样长时，m 就是中点；这条"一样长"翻译成算式，就是两头的平均数。

必记 · 中点公式

数轴上两点 𝑎、𝑏 的中点 =𝑎+𝑏2。
读法：把两头的数加起来，再对半分。就这么一句，小数、负数、谁左谁右都一样。

公式是怎么来的

设中点是 x。中点的意思是"x 到 a 和 x 到 b 一样远"，用第 03 节的写法就是：

推导（只用一维的距离，不用任何别的知识）

推导（只用一维的距离，不用任何别的知识）

推导（只用一维的距离，不用任何别的知识）

① 一样远：|𝑥 −𝑎| =|𝑏 −𝑥|

② 把绝对值取掉：左边那段是 x − a，右边那段是 b − x。因为 x 夹在 a、b 中间，这两个都是正数，而两个绝对值相等，所以它们直接相等。

又因为 x 在中间，x − a 与 b − x 都是正的，所以它们直接相等：

③ 𝑥 −𝑎 =𝑏 −𝑥

④ 把 x 挪到一边：2𝑥 =𝑎 +𝑏

⑤ 两边除以 2：𝑥 =(𝑎 +𝑏) ÷2 —— 正好是平均数。

不用管谁在左边

第 ④ 步的 2𝑥 =𝑎 +𝑏 是个对称式：a 和 b 换个位置，结果一模一样。所以 (a + b) ÷ 2 对任意两个数都成立，不管 a 在左还是 b 在左。即使是负数，照样相加再对半分。

例题 5

题目　求数轴上 −3 与 5 的中点。

① 代入公式：( −3 +5) ÷2 =2 ÷2 =1。

② 验算：1 到 −3 的距离是 |1 −( −3)| =4；1 到 5 的距离是 |5 −1| =4。一样长，对。

③ 全长是 8，一半是 4，从 −3 往右走 4 格正好到 1。三种看法同一个答案。

旁注

中点不一定是"中间那个整数"，也可能带小数，甚至可能等于 0——它只是位置，没有必须"好看"的要求。

例题 6

题目　求 −7.5 与 3.5 的中点。

① ( −7.5 +3.5) ÷2 =( −4) ÷2 = −2。

② 验算：−2 到 −7.5 是 5.5；−2 到 3.5 是 5.5。一样长。

旁注

跨 0 的两点，中点可能落在原点的任一侧。先加后除，负号照常参加运算，不用特殊处理。

两个最常见的错
  • 只加不除以 2：3 和 9 的中点答 12。12 是"两段长度之和"，不是中点。
  • 把距离的一半当中点：−3 和 5，全长 8，一半是 4，于是答 4——正好差了一半的位置。4 是长度的一半，不是位置。要从一个端点出发把这一半走过去。

反过来用：知道中点，求另一头

中点公式可以变形。已知两端 a、b 和中点 x 中的两个，第三个就能求出来。最常用的一种是：

逆用

𝑏 =2𝑥 −𝑎（已知一端 𝑎 和中点 𝑥，求另一端 𝑏）
理由很简单：𝑥 =(𝑎 +𝑏) ÷2 两边乘 2 得 2𝑥 =𝑎 +𝑏，再减去 a 就得到 b。这就是你在整式化简里练过的那种变形。

例题 7

题目　数轴上 A 表示 −2，M 是 AB 的中点且 M 表示 3，求 B 表示的数。

① 用逆用公式：𝑏 =2 ×3 −( −2) =6 +2 =8。

② 验算：−2 与 8 的中点 ( −2 +8) ÷2 =3。对。

③ 换一种想法：−2 到 3 是 5 个单位，中点两边一样长，所以 3 再往右走 5 格到 8。两法一致。

例题 8

题目　数轴上有一个点 x，它到 −2 和到 3 的距离相等。这个点在哪儿？是不是只有这一个答案？

① 距离相等 ⇒ 它在 −2 与 3 的中点，这是中点公式的逆用。

② 𝑥 =( −2 +3) ÷2 =0.5。

③ 检查有没有别的答案：点如果在 −2 左边，它离 −2 近、离 3 更远，不相等；如果在 3 右边，离 3 近、离 −2 更远，也不相等。所以只有 0.5 一个答案。

旁注

"距离相等"和"距离等于某个数"不同：后者左右各一个点，前者只有中点一个点。问一句"另一侧有没有可能"，能挡掉大半错误。

练习 05

  1. 求 −4 与 6 的中点。
  2. 求 −5 与 −1 的中点。
  3. 求 −2.5 与 4.5 的中点。
  4. A 表示 7，M 是中点且表示 2，求 B。
  5. 3 和 9 的中点是多少？12 是什么数？
  6. 数轴上一把尺子，2 厘米刻度与 5 厘米刻度的中点对着几厘米？
答案
  1. (−4 + 6) ÷ 2 = 1。 2. (−5 − 1) ÷ 2 = −3。 3. (−2.5 + 4.5) ÷ 2 = 1。 4. b = 2 × 2 − 7 = −3。 5. 中点是 6；12 是 3 + 9（两数之和），没有除以 2。 6. (2 + 5) ÷ 2 = 3.5 厘米。刻度就是位置，位置的中点一样用平均数算。

06 一整段路，三个数各是什么身份（≈15 分钟）

前面五节其实只讲了三样东西。把它们放在同一张图上对照，以后看到一个数，先问一句：它现在是身份 A、B 还是 C？

坐标、距离、中点：三个数的身份

同一段 𝐴𝐵：A、B、M 是位置（坐标），4 和 8 是距离，M 表示的 1 是位置。

要点 说明
身份 A · 坐标 点在数轴上的位置，可以带负号，可以是一个分数。𝐴 = −3 就是"在原点左边 3 格"。可正可负。
身份 B · 距离 两点之间的长度，永远 ≥ 0，没有方向。$AB =
身份 C · 中点 两端坐标的平均数。𝑀 =( −3 +5) ÷2 =1，它自己也是一个坐标。可能是负的，也可能正好是 0。
一句话分清三个身份

坐标看位置（带方向，可负）；距离看长短（不带方向，非负）；中点看平均数（两头加起来对半分）。一个数到底是哪一个，看它在算式的哪个位置，不看它长什么样。

综合练习

  1. 数轴上 A 表示 −6，B 表示 2。求 AB 的长度、求 AB 的中点 M。
  2. 承接上题：点 P 在线段 AB 上且 AP = 3，求 P 表示的坐标。
  3. 已知 |𝑥 −1| =4，求 x，并说出这两个点关于哪个点对称。
  4. 小明说"−3 和 −7 之间隔了 10 个单位"。错在哪里？正确是多少？
  5. 用一句话说明：为什么"右边减左边"一定大于 0？
答案
  1. 𝐴𝐵 =|2 −( −6)| =8；𝑀 =( −6 +2) ÷2 = −2。 2. P 离 A 有 3 个单位，且在 A、B 之间（A 在左），所以往右走 3 格：−6 +3 = −3。P 表示 −3。 3. x 离 1 有 4 个单位，所以 x = 5 或 x = −3。这两个点关于 1 对称，1 正是它们的中点。 4. 错在"大减小"：−3 在 −7 右边，距离是 ( −3) −( −7) =4；如果按 | −3| + | −7| = 10 算，那是把两点当成了分别在原点两侧，可它们都在左边。 5. 因为"往右"被规定为正方向，从左边那个数往右走到右边那个数需要走正格数，这个格数正是"右减左"的结果。

自测 这一讲的清单

全部打勾才算过关

  • 我能说出数轴的三个要素，并解释"为什么左边的数小"。
  • 我能用"右减左、看正负"比较任意两个数的大小。
  • 我能说出 |a| 是"到原点的距离"，并能正确算出 −| −4|。
  • 我能直接写出两点距离 |𝑎 −𝑏|，不需要先判断谁在左边。
  • 我能解释跨 0 时为什么是"绝对值相加"，而不是"相减"。
  • 我会用 (𝑎 +𝑏) ÷2 求中点，也会反过来求另一个端点。
  • 我能分清坐标、距离、中点三个身份，看到题目先说清是哪一个。
课后怎么用
  1. 这一讲的"一句话"要能不看讲义说出来。 2. 练习错的题，隔一天重做一遍，只做错的那几道。 3. 每道距离题都画一条数轴，把点标上——画图 10 秒，能省掉大部分符号错误。 4. 遇到"跨 0"的题，习惯用两种算法互相验证。
和课本的关系

课本正文讲的是绝对值是"到原点的距离"，以及 |𝑎 −𝑏| 表示两点间距离。而两点距离公式与中点公式，在很多版本的七上教材里放在"数轴"拓展或后续章节，属于用图形解决问题的部分。学完这一讲，回到课本会发现：所有公式你都见过，缺的只是那根数轴。
